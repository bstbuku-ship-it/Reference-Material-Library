# 📚 素材参考库 v1.6.0

> 把灵感收进自己的素材库：分类、九宫格、截图画廊一应俱全，原图只存本地硬盘。

> 一款专为内容创作者设计的本地灵感素材管理工具，以浏览器扩展形态常驻工具栏，一键打开，无需每次手动加载文件。

---

## ✨ 功能特色

* 🧩 **浏览器扩展形态** — 点击工具栏图标即可打开，无需再手动拖拽 HTML 文件
* 🗂️ **素材分类管理** — 自定义分类目录，卡片式瀑布流展示
* 🖼️ **图集全览** — 双击素材卡片或点击侧边导航栏，均可快速进入图集全览大图浏览
* 🔲 **九宫格排版预览** — 一键查看多图排版效果，截图收进来也是九宫格排着看；全选后拖一张就是拖整组
* 🔎 **大图查看** — 画廊里点开大图，滚轮按鼠标指的位置放大，放大后按住拖动看局部，键盘左右键切换上一张／下一张
* 🖼️ **图片存在本地** — 原图只存本地硬盘，不上传任何服务器
* 📁 **目录记忆授权** — 自动记住上次连接的本地文件夹，下次打开只需一次授权确认，无需重新选择目录
* 🗑️ **防丢回收站** — 删除有后悔药，支持永久清除；还可以设置自动清理，按保留天数或占用大小
* 🔍 **搜索与标签** — 搜索框记住最近 3 条记录，点搜索框就弹出来，点一条直接搜；输入后点一下小叉就清空；标签输入有建议，搜到的词会高亮
* 🧺 **批量操作** — 按住 Ctrl 点多张，或者在空白处拖出框来圈选；选好后可以批量删除，或者合并成一项（原图、标签、链接都并进来）；画廊里也能在放图区域的空白处拖框圈选
* 🖼️ **图片加载** — 图片质量可选原图或 1.0～0.5 的压缩小图；打开「节省内存」后详情只加载封面、打开画廊才加载剩下的图，加载吃力或内存告急时会提醒打开
* ⚙️ **设置左侧导航** — 外观主题、图片加载、回收站、数据与备份、关于，点左边换右边
* 🌗 **深色 / 亮色主题** — 浅色、深色、跟随系统，三段切换
* 💾 **数据备份与恢复** — 一键导出 JSON 备份，需要时导入恢复
* 🔄 **自动更新检测** — 启动时静默检测新版本，有更新弹窗提示；也可以在设置 → 关于里手动检查

## 🚀 安装与使用方法

### 安装扩展

1. 下载最新版本的扩展压缩包并解压
2. 打开浏览器（推荐 **Chrome 或 Edge**），进入扩展管理页面：
   - Chrome：地址栏输入 `chrome://extensions`
   - Edge：地址栏输入 `edge://extensions`
3. 打开右上角「开发者模式」
4. 点击「加载已解压的扩展程序」，选择解压后的文件夹
5. 安装完成后，工具栏会出现「素材参考库」图标

### 开始使用

1. 点击工具栏图标打开插件
2. 首次使用点击「选择/连接文件夹」，授权一个本地文件夹用于存储图片和数据
3. 之后每次打开会自动记住该文件夹，只需确认授权即可继续使用
4. 开始添加素材 🎉

> ⚠️ 建议使用 **Chrome / Edge**，以获得完整的本地硬盘直读直写功能。

## 🔄 版本更新

扩展启动后会自动检测是否有新版本发布，有更新时会弹窗提示，按提示下载并重新加载扩展即可。旧版本本地数据文件夹无需迁移，重新连接授权后即可继续使用。

## 📁 数据说明

所有数据保存在你本地授权的文件夹中：

```
你选择的文件夹/
├── database.json       # 素材元数据（标题、标签、链接等）
├── workspace.json      # 工作台数据
├── .thumbs/            # 缩略图缓存
└── [分类名称]/
    └── [素材名称]/
        ├── 图片1.jpg
        └── 图片2.jpg
```

数据完全本地，不上传任何服务器。
